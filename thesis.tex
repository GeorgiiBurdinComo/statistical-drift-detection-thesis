\abstract{%
\textbf{1. Context}\\
Gocomo uses API-based large language models (LLMs) for campaign-relevance classification on social-media posts.

\textbf{2. Practical Problem}\\
These API models change over time without full transparency, so the performance of a deployed classification pipeline may degrade.

\textbf{3. Operational Constraint}\\
Re-running a full benchmark frequently is too expensive.

\textbf{4. Methodological Problem}\\
Therefore, a framework is needed that can:
\begin{itemize}
    \item represent the task consistently,
    \item monitor performance over time with a smaller but informative sample,
    \item detect drift statistically,
    \item support informed model selection using accuracy, precision, recall, F1, and cost,
    \item and possibly recover performance through prompt optimisation.
\end{itemize}
