\chapter{Paired Drift Monitoring and Alerting}
\label{ch:drift}

\noindent Monitoring tests whether regressions outnumber improvements on the same labelled posts between two runs. The chapter therefore uses a one-sided exact McNemar test on paired correctness transitions.

\section{Fixed-panel comparison design}
\label{sec:formalisation-temporal}

This section states the paired monitoring setup used by the alert: the correctness representation from Chapter~\ref{ch:data}, the fixed-contract comparison condition, and the effective denominator induced by complete pairs.

\paragraph{Recall of the monitoring representation.}

Chapter~\ref{ch:data} defines the binary correctness indicator
\begin{equation}
    E_{i,t}(q)=\mathbb{I}\{\hat y_{i,t}(q)=y_i\}
    \label{eq:correctness-indicator}
\end{equation}
and the corresponding finite-panel accuracy
\begin{equation}
    A_n(q,t)
    =
    \frac{1}{n}\sum_{i=1}^{n}E_{i,t}(q).
    \label{eq:chapter3-panel-accuracy}
\end{equation}
for a fixed client-controlled request contract \(q\). This chapter applies that representation to paired monitoring across two evaluation times. As discussed in Chapter~\ref{ch:data}, provider-side hidden state can still change across evaluation times \(t=0,1,\ldots\).

\paragraph{Fixed evaluation contract.}

The monitoring comparison relies on the following design condition:

\begin{assumption}[Fixed evaluation contract]
Between the two runs being compared, the panel identifiers, reference labels, prompt, parsing rule, and intended API configuration are unchanged. Each retained record is aligned by item identifier.
\label{ass:fixed-evaluation-contract}
\end{assumption}

\paragraph{Complete pairs and effective denominator.}

The stored panel contains 300 items, but an API run can have missing outputs. A valid paired comparison uses only items observed and scored at both times. For baseline \(t_1\) and follow-up \(t_2\), define the complete-pair set
\[
\mathcal{C}(q,t_1,t_2)
=
\{i:\text{item \(i\) has a valid scored result at both \(t_1\) and \(t_2\)}\}
\]
and the corresponding effective denominator
\[
n_{12}=|\mathcal{C}(q,t_1,t_2)|\le 300.
\]
All counts and both accuracy values in one paired comparison use this same complete-pair set. To keep the formulas readable, the rest of the derivation writes \(n=n_{12}\) and sums over the retained items. This is why an empirical comparison can legitimately report, for example, \(n=296\) rather than 300.

This rule keeps the denominator matched across the two runs. It does not solve selective failures: if missing outputs happen more often on hard items, the retained pairs can make performance look too favourable. Every result must therefore report the effective \(n\) and the provider or parsing failures alongside the test.

\section{Paired correctness and observed degradation}

Pairing shows which same posts regressed and which improved between the two runs. For the fixed configuration \(q\), which is suppressed below, the same item appears at the baseline and follow-up, so its two correctness values form a pair,
\[
\bigl(E_{i,t_1},E_{i,t_2}\bigr).
\]
Treating the two runs as unrelated samples would discard useful information. A change from \(1\) to \(0\) is direct evidence of regression on one item, whereas a pair \((1,1)\) contributes to both accuracy levels without showing temporal change.

There are exactly four possible paired outcomes, shown in Table~\ref{tab:mcnemar_contingency_design} in Chapter~\ref{ch:data}. Write \(a\) for stayed correct \((1,1)\), \(b\) for regressed \((1,0)\), \(c\) for improved \((0,1)\), and \(d\) for stayed wrong \((0,0)\).

The four cells partition the complete pairs, so
\begin{equation}
    a+b+c+d=n.
    \label{eq:paired-count-total}
\end{equation}
The directional notation is fixed throughout the thesis:
\begin{align}
    b
    &=
    \sum_{i=1}^{n}
    \mathbb{I}\{E_{i,t_1}=1,E_{i,t_2}=0\},
    \label{eq:regression-count}\\
    c
    &=
    \sum_{i=1}^{n}
    \mathbb{I}\{E_{i,t_1}=0,E_{i,t_2}=1\}.
    \label{eq:improvement-count}
\end{align}
Thus \(b\) always means ``correct to wrong'', whereas \(c\) always means ``wrong to correct''.

\paragraph{Observed accuracy change.}

The paired effect size is the follow-up accuracy minus the baseline accuracy on the same retained items. At baseline, the correct items are those in cells \(a\) and \(b\). Therefore
\[
A_n(q,t_1)=\frac{a+b}{n}.
\]
At follow-up, the correct items are those in cells \(a\) and \(c\). Therefore
\[
A_n(q,t_2)=\frac{a+c}{n}.
\]
Subtracting the baseline accuracy from the follow-up accuracy gives
\begin{align}
A_n(q,t_2)-A_n(q,t_1)
&=\frac{a+c}{n}-\frac{a+b}{n}\\
&=\frac{a+c-a-b}{n}\\
&=\frac{c-b}{n}.
\label{eq:paired-accuracy-change}
\end{align}
The count \(a\) cancels. The count \(d\) appears in neither accuracy numerator. Consequently, only the two \emph{discordant} cells \(b\) and \(c\) determine the change. For example, \(18\) regressions and \(5\) improvements among \(296\) complete pairs give
\[
\Delta A_{\mathrm{paired}}=\frac{18-5}{296}=0.0439,
\]
that is, a paired degradation of \(4.4\) percentage points.

Equation~\eqref{eq:paired-accuracy-change} immediately gives the direction:
\[
\begin{array}{lll}
b>c &\Longrightarrow& \text{accuracy decreased},\\
b=c &\Longrightarrow& \text{accuracy did not change},\\
b<c &\Longrightarrow& \text{accuracy increased}.
\end{array}
\]
It is convenient to express a positive degradation magnitude as
\begin{equation}
    \Delta A_{\mathrm{paired}}
    =
    A_n(q,t_1)-A_n(q,t_2)
    =
    \frac{b-c}{n}.
    \label{eq:observed-drop}
\end{equation}

\section{Exact directional McNemar test}
\label{sec:mcnemar-section}

The panel drop \((b-c)/n\) is the observed effect size. McNemar's test is the standard test for paired binary outcomes on the same items, so it matches the fixed-panel before-and-after comparison in this chapter. In the paired correctness table, only the discordant cells \(b\) and \(c\) carry evidence about change, since the concordant cells \(a\) and \(d\) contribute equally to both runs. A standard large-sample variant summarizes the discordant imbalance by
\[
\chi^2=\frac{(b-c)^2}{b+c},
\]
but the operational rule in this thesis uses the exact one-sided form because the monitoring question is directional and the discordant count can be small~\cite{mcnemar1947}.

\paragraph{Directional hypotheses.}

For monitoring, the relevant alternative is directional degradation. Write \(p_b\) for the probability of regression and \(p_c\) for the probability of improvement on one paired item. The hypotheses are
\begin{equation}
H_0:p_b\le p_c
\qquad\text{against}\qquad
H_a:p_b>p_c.
\label{eq:mcnemar-hypotheses}
\end{equation}
In words:
\begin{description}
    \item[\(H_0\)] regression is no more likely than improvement on the fixed panel, including equal probabilities and situations in which improvement is more likely;
    \item[\(H_a\)] regression is more likely than improvement, which is the directional degradation signal of interest.
\end{description}

\paragraph{One-sided exact p-value.}

Let \(D=b+c\) be the discordant count and let \(b_{\mathrm{obs}}\) be the observed number of regressions. If \(B\) denotes the random number of regressions among these \(D\) discordant pairs, then under \(H_0\),
\[
    B\mid D\sim\mathrm{Binomial}(D,1/2).
\]
The exact one-sided McNemar p-value is therefore the upper-tail probability
\[
p_{\mathrm{exact}}
=
\sum_{j=b_{\mathrm{obs}}}^{D}\binom{D}{j}2^{-D}.
\]
At per-comparison level \(\alpha\), reject when
\begin{equation}
    b>c
    \qquad\text{and}\qquad
    p_{\mathrm{exact}}\le\alpha.
    \label{eq:nominal-rejection-rule}
\end{equation}
Equation~\eqref{eq:nominal-rejection-rule} is the thesis-specific reject-or-do-not-reject rule: when both conditions hold, the test rejects \(H_0\); otherwise it does not reject \(H_0\). 

\paragraph{Scope of rejection.}

Rejection is evidence of directional degradation on the frozen panel under the working model. It does not by itself identify the cause, quantify production impact, or choose a replacement.

\section{Diagnostics and escalation}
\label{sec:classification-metrics}

For each configuration \(q\), every later eligible run is compared with that configuration's earliest eligible panel run \(t_0\).

The monitoring rule opens review on the fixed panel. Review then checks the trajectory across runs, the effective pair counts, the same-batch controls, and the class-specific error composition, especially the balance between false positives and false negatives. These diagnostics explain the source and operational relevance of the change, but they do not modify the McNemar rejection rule.

When the panel signal and its diagnostics support escalation, the next step is a broader rerun on the full benchmark \(\mathcal{D}_N\) of 1199 labelled posts. That rerun serves a different role from the sentinel panel: it supplies the common-case false-positive counts, false-negative counts, and inference charges required for deployment comparison across candidate configurations. Chapter~\ref{ch:cost-deployment-utility} uses those benchmark outcomes to rank candidates under declared task-specific losses and to support the replacement decision.
