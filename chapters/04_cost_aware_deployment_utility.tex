\chapter{Cost-Aware Deployment Decisions}
\label{ch:cost-deployment-utility}

\noindent This chapter ranks candidate replacements on common full-benchmark cases using observed API charges and explicit false-positive and false-negative penalties. The result is conditional on declared error prices and observed inference charges. It applies cost-sensitive decision analysis after inference rather than training a cost-sensitive classifier~\cite{elkan2001cost,turney2000cost}.

\section{Common evaluation basis and cost components}

Candidate ranking is meaningful only when every candidate is scored on the same requests and every cost term has a declared meaning. This section fixes the common evaluation subset and defines the three inputs to loss: mean API charge, false positives, and false negatives.

\paragraph{Candidate set and common complete cases.}

Every candidate must be scored on the same items. Otherwise a loss difference could come from different item sets rather than different model behaviour. Let
\[
\mathcal{M}_{\mathrm{cand}}
=
\{m_1,\ldots,m_J\}
\]
be the set of candidate model--prompt configurations considered at evaluation time \(t\). Each candidate must be judged on the same items.

Define the \emph{common complete-case benchmark set}
\begin{equation}
    \mathcal{B}_t
    =
    \left\{
        (x_i,y_i)\in\mathcal{D}_N:
        \begin{array}{l}
        \text{the reference label is available, and}\\
        \text{every candidate has a parsed prediction and usage record}
        \end{array}
    \right\}.
    \label{eq:common-complete-case-set}
\end{equation}
Write
\begin{equation}
    n_t=|\mathcal{B}_t|,
    \qquad
    n_t>0.
    \label{eq:common-complete-case-size}
\end{equation}

The intersection is important. If one candidate were evaluated on easy items and another on difficult items, a loss difference could be caused by item composition rather than model behaviour. A common set removes denominator mismatch. Informative missingness remains, so coverage and exclusion counts accompany the ranking.

\paragraph{Observed cost components.}

The ranking uses the following observed quantities and scenario parameters:
\begin{description}
    \item[\(r_{i,t}(m)\)] observed token-derived API charge in USD for item \(i\) under candidate \(m\);
    \item[\(c_t(m)\)] mean inference charge of candidate \(m\) on the common complete-case set;
    \item[\(I^{\mathrm{FP}}_{i,t}(m)\)] false-positive indicator for item \(i\) under candidate \(m\);
    \item[\(I^{\mathrm{FN}}_{i,t}(m)\)] false-negative indicator for item \(i\) under candidate \(m\);
    \item[\(C_{\mathrm{FP}},C_{\mathrm{FN}}\)] scenario penalties in USD per false positive and USD per false negative.
\end{description}
The formal definitions are as follows. The mean inference charge is
\begin{equation}
    c_t(m)
    =
    \frac{1}{n_t}
    \sum_{i\in\mathcal{B}_t}r_{i,t}(m)
    \qquad
    \text{USD per request}.
    \label{eq:mean-inference-charge}
\end{equation}

Define the false-positive and false-negative indicators
\begin{align}
I^{\mathrm{FP}}_{i,t}(m)
&=
\mathbb{I}\{y_i=0,\hat y_{i,t}(m)=1\},\\
I^{\mathrm{FN}}_{i,t}(m)
&=
\mathbb{I}\{y_i=1,\hat y_{i,t}(m)=0\}.
\end{align}
Their sums are the observed error counts:
\begin{align}
\mathrm{FP}_t(m)
&=
\sum_{i\in\mathcal{B}_t}I^{\mathrm{FP}}_{i,t}(m),\\
\mathrm{FN}_t(m)
&=
\sum_{i\in\mathcal{B}_t}I^{\mathrm{FN}}_{i,t}(m).
\end{align}

The penalties satisfy
\[
C_{\mathrm{FP}}\ge0
\qquad\text{and}\qquad
C_{\mathrm{FN}}\ge0.
\]
They are not estimated from the benchmark. They may represent analyst correction time, a contaminated report, a missed signal, or another downstream consequence. Correct predictions add no business-error penalty in this model.

\section{Empirical loss and candidate selection}

The three components become comparable only after they are placed on one additive scale. This section converts API cost and error penalties into one USD-per-request loss and then selects the candidate with the smallest value.

\paragraph{Loss derivation.}

The purpose of the loss is to express the cost of one candidate over the common benchmark without giving any component an implicit weight. The observed total inference charge for candidate \(m\) is
\[
\sum_{i\in\mathcal{B}_t}r_{i,t}(m)
=
n_t c_t(m).
\]
The assigned total error penalty is
\[
C_{\mathrm{FP}}\mathrm{FP}_t(m)
+
C_{\mathrm{FN}}\mathrm{FN}_t(m).
\]
Adding these components gives total assigned benchmark cost:
\[
n_t c_t(m)
+
C_{\mathrm{FP}}\mathrm{FP}_t(m)
+
C_{\mathrm{FN}}\mathrm{FN}_t(m).
\]
To compare candidates on a per-request scale, divide by the common \(n_t\):
\begin{equation}
\begin{split}
L_t(m)
&=
\frac{
    n_t c_t(m)
    +C_{\mathrm{FP}}\mathrm{FP}_t(m)
    +C_{\mathrm{FN}}\mathrm{FN}_t(m)
}{n_t}\\
&=
c_t(m)
+
\frac{
    C_{\mathrm{FP}}\mathrm{FP}_t(m)
    +C_{\mathrm{FN}}\mathrm{FN}_t(m)
}{n_t}.
\end{split}
\label{eq:expected-cost}
\end{equation}

Every term now has the same unit, USD per evaluated request:
\[
\underbrace{c_t(m)}_{\text{USD/request}}
+
\underbrace{
C_{\mathrm{FP}}\frac{\mathrm{FP}_t(m)}{n_t}
}_{\text{USD/error}\times\text{errors/request}}
+
\underbrace{
C_{\mathrm{FN}}\frac{\mathrm{FN}_t(m)}{n_t}
}_{\text{USD/error}\times\text{errors/request}}.
\]
This unit check verifies that the addition in Equation~\eqref{eq:expected-cost} is meaningful.

\paragraph{Finite-benchmark interpretation.}

The counts and charges are observed on \(\mathcal{B}_t\), while the penalties are scenario inputs. Thus \(L_t(m)\) is the observed per-request loss on the common complete cases under the chosen false-positive and false-negative penalty scenario. Changing the penalties changes the decision problem.

\paragraph{Minimum-loss candidate.}

Once the common set, components, and penalties are fixed, candidate selection requires no additional score. The deployment rule is
\begin{equation}
    m_t^\star
    \in
    \arg\min_{m\in\mathcal{M}_{\mathrm{cand}}}
    L_t(m).
    \label{eq:model-selection}
\end{equation}
The set-valued \(\arg\min\) allows ties, which require a declared secondary rule.

\paragraph{Illustrative operating point.}
At \(C_{\mathrm{FP}}=0.155\) USD and \(C_{\mathrm{FN}}=0.031\) USD, the canonical export selects \texttt{gpt-5-mini}. Later sections vary the ratio and absolute scale of these penalties to show how the ranking moves.

\section{Encoding cost preferences}
\label{sec:cost-parameters-uncertainty}

One pair \((C_{\mathrm{FP}},C_{\mathrm{FN}})\) gives one ranking, but it hides why the ranking changes. The reparameterisation below separates two questions: how much more costly is a false negative than a false positive, and how important are business errors relative to API price.

\paragraph{Relative importance and total severity.}

For \(C_{\mathrm{FP}}>0\), define
\begin{equation}
    w
    =
    \frac{C_{\mathrm{FN}}}{C_{\mathrm{FP}}},
    \qquad
    \lambda
    =
    C_{\mathrm{FP}}+C_{\mathrm{FN}}.
    \label{eq:R-lambda-definition}
\end{equation}
These two preference parameters have distinct roles:
\begin{description}
    \item[\(w\)] false-negative penalty relative to a false positive, with \(w\ge0\);
    \item[\(\lambda\)] absolute severity of errors relative to an API call, with \(\lambda>0\).
\end{description}
Both parameters are required: the ratio alone does not decide whether a more accurate expensive model is justified.

\paragraph{Recovering the original penalties.}

The inverse transformation is
\begin{equation}
    C_{\mathrm{FP}}
    =
    \frac{\lambda}{1+w},
    \qquad
    C_{\mathrm{FN}}
    =
    \frac{\lambda w}{1+w}.
    \label{eq:penalties-from-R-lambda}
\end{equation}

\paragraph{Preference-parameterised loss.}

Substitution into Equation~\eqref{eq:expected-cost} gives
\begin{align}
L_t(m;w,\lambda)
&=
c_t(m)
+
\frac{\lambda}{1+w}
\frac{
    \mathrm{FP}_t(m)+w\mathrm{FN}_t(m)
}{n_t}.
\label{eq:expected-cost-lambda-R}
\end{align}
Increasing \(\lambda\) makes business errors matter more relative to API cost; changing \(w\) makes false negatives more or less expensive relative to false positives. Figure~\ref{fig:cost-penalty-map} shows the same ranking in the raw penalty coordinates \(C_{\mathrm{FN}}\) and \(C_{\mathrm{FP}}\): pick one penalty pair, read the region label at that point, and crossing a boundary changes the preferred candidate. Panel~(a) uses linear axes from \(0\) to \(10\) USD; panel~(b) uses logarithmic axes over \(10^{-2}\) to \(10\) USD so that the near-origin transitions remain visible.

\section{Sensitivity and break-even analysis}
\label{sec:break-even-analysis}

Because the penalties are scenario inputs rather than measured constants, reporting only one minimiser would hide decision uncertainty. A pairwise break-even boundary is the set of penalty values where two candidates have equal loss; on opposite sides of the boundary, the preferred candidate changes.

\paragraph{Pairwise loss difference.}

The absolute losses are not needed to locate a preference switch; subtracting them isolates the component trade-offs between two candidates. For candidates \(m_i\) and \(m_j\), the comparison uses:
\begin{description}
    \item[\(\Delta_{i,j}c_t\)] difference in mean inference charge;
    \item[\(\Delta_{i,j}\mathrm{FP}_t\)] difference in observed false-positive count;
    \item[\(\Delta_{i,j}\mathrm{FN}_t\)] difference in observed false-negative count.
\end{description}
These component differences in the direction \(i-j\) are
\begin{align}
\Delta_{i,j}c_t
&=
c_t(m_i)-c_t(m_j),\\
\Delta_{i,j}\mathrm{FP}_t
&=
\mathrm{FP}_t(m_i)-\mathrm{FP}_t(m_j),\\
\Delta_{i,j}\mathrm{FN}_t
&=
\mathrm{FN}_t(m_i)-\mathrm{FN}_t(m_j).
\label{eq:candidate-differences}
\end{align}
A negative difference favours \(m_i\) for that component; a positive difference favours \(m_j\).

Subtract the two losses:
\begin{align}
\Delta_{i,j}L_t
&=
L_t(m_i)-L_t(m_j)\\
&=
\Delta_{i,j}c_t
+
\frac{
    C_{\mathrm{FP}}\Delta_{i,j}\mathrm{FP}_t
    +C_{\mathrm{FN}}\Delta_{i,j}\mathrm{FN}_t
}{n_t}.
\label{eq:pairwise-loss-difference}
\end{align}
Candidate \(m_i\) is preferred when \(\Delta_{i,j}L_t<0\), tied at zero, and otherwise disfavoured.

\paragraph{Direct break-even boundary.}

A boundary is the set of assumptions at which neither candidate is preferred, so it is obtained by setting the pairwise difference to zero:
\begin{equation}
    \Delta_{i,j}c_t
    +
    \frac{
        C_{\mathrm{FP}}\Delta_{i,j}\mathrm{FP}_t
        +C_{\mathrm{FN}}\Delta_{i,j}\mathrm{FN}_t
    }{n_t}
    =0.
    \label{eq:break-even-count}
\end{equation}
This states how weighted error savings offset inference-cost differences.

\paragraph{Break-even severity for fixed \(w\).}

For fixed \(w\), solving Equation~\eqref{eq:break-even-count} gives
\begin{equation}
\lambda_{i,j}^\star(w)
=
-\frac{
    n_t(1+w)\Delta_{i,j}c_t
}{
    \Delta_{i,j}\mathrm{FP}_t
    +w\Delta_{i,j}\mathrm{FN}_t
}.
\label{eq:lambda-breakpoint}
\end{equation}

Use this breakpoint only when the denominator is nonzero and \(\lambda^\star>0\). Then check the sign of the loss difference on each side of the breakpoint to see which candidate is preferred.

\paragraph{Break-even relative penalty for fixed \(\lambda\).}

For fixed \(\lambda\), the corresponding boundary is
\begin{equation}
w_{i,j}^\star(\lambda)
=
-\frac{
    n_t\Delta_{i,j}c_t
    +\lambda\Delta_{i,j}\mathrm{FP}_t
}{
    n_t\Delta_{i,j}c_t
    +\lambda\Delta_{i,j}\mathrm{FN}_t
}.
\label{eq:R-breakpoint}
\end{equation}
Require a nonzero denominator and \(w^\star\ge0\). Across candidate pairs, these boundaries divide the \((w,\lambda)\) plane into regions where the same candidate minimises the loss.

\paragraph{Worked comparison.}
Against \texttt{gpt-5-nano}, \texttt{gpt-5-mini} has \((\Delta c,\Delta\mathrm{FP},\Delta\mathrm{FN})=(0.0009468,0,-43)\) on \(n_t=1112\). Mini costs more per call, matches nano on false positives, and avoids 43 false negatives. At \(w=0.2\), the break-even severity is \(\lambda^\star=0.1469\) USD; the illustrative point \((w,\lambda)=(0.2,0.186)\) therefore still favours mini.

\paragraph{Dominance.}

Candidate \(m_i\) dominates \(m_j\) if
\begin{equation}
c_t(m_i)\le c_t(m_j),
\qquad
\mathrm{FP}_t(m_i)\le\mathrm{FP}_t(m_j),
\qquad
\mathrm{FN}_t(m_i)\le\mathrm{FN}_t(m_j),
\label{eq:dominance-conditions}
\end{equation}
with at least one strict inequality. Under nonnegative penalties, \(m_j\) then cannot have lower loss and may be removed without deleting a unique minimiser.

\section{Business scenarios}
\label{sec:constraint-based-selection}

The loss map turns policy assumptions into model choices. If missed or extra posts are cheap, a lower-cost candidate can be preferred. If missing relevant posts matters most, impose a recall target or a budget ceiling and then optimise within that feasible set. If no manual review is available, impose a precision floor first and only then compare recall and cost. These are policy choices; the measured candidate counts determine which models are feasible in each scenario.

\paragraph{Minimum recall, then minimum API charge.}

Let \(\tau_{\mathrm{rec}}\in[0,1]\) be the minimum acceptable recall. Define the feasible set
\[
\mathcal{F}_{\mathrm{rec}}
=
\left\{
    m\in\mathcal{M}_{\mathrm{cand}}:
    \mathrm{Recall}_t(m)\ge\tau_{\mathrm{rec}}
\right\}.
\]
Among these candidates, choose the one with the lowest mean inference charge:
\begin{equation}
m_t^\star(\tau_{\mathrm{rec}})
\in
\arg\min_{\substack{m\in\mathcal{M}_{\mathrm{cand}}\\
\mathrm{Recall}_t(m)\ge\tau_{\mathrm{rec}}}}
c_t(m).
\label{eq:recall-constrained-selection}
\end{equation}
This rule is appropriate when missing relevant posts must be controlled first and API price is secondary.

\paragraph{Maximum API budget, then minimum miss rate.}

Let \(B\ge0\) be the maximum acceptable mean inference charge in USD per request. The feasible set is
\[
\mathcal{F}_{B}
=
\{m\in\mathcal{M}_{\mathrm{cand}}:c_t(m)\le B\}.
\]
Among candidates within budget, choose the lowest false-negative rate:
\begin{equation}
m_t^\star(B)
\in
\arg\min_{\substack{m\in\mathcal{M}_{\mathrm{cand}}\\
c_t(m)\le B}}
\mathrm{FNR}_t(m).
\label{eq:budget-constrained-selection}
\end{equation}
Because \(\mathrm{FNR}=1-\mathrm{Recall}\) when positives occur, this is equivalent to maximizing recall within the budget.

\paragraph{Minimum precision, then maximum recall.}

Let \(\tau_{\mathrm{prec}}\in[0,1]\) be the minimum acceptable precision. First remove candidates below that threshold; then maximize recall:
\begin{equation}
m_t^\star(\tau_{\mathrm{prec}})
\in
\arg\max_{\substack{m\in\mathcal{M}_{\mathrm{cand}}\\
\widehat{\mathrm{Precision}}_t(m)\ge\tau_{\mathrm{prec}}}}
\mathrm{Recall}_t(m).
\label{eq:precision-constrained-selection}
\end{equation}
This rule limits the share of predicted positives that are irrelevant, then finds as many relevant items as possible among the acceptable candidates.

\paragraph{Edge cases.}

If the feasible set is empty, return no candidate. If several candidates tie, apply a declared secondary rule. If a required rate is undefined, that candidate cannot establish feasibility.

\section{Decision scope and monitoring handoff}

This ranking applies only to the current candidate roster, the common full-benchmark cases, the observed charges, and the declared penalties. The sentinel panel can trigger review, but it never supplies the FP/FN counts used for candidate ranking. When loss gaps are small, report a sensitivity region and review the decision before deployment.

Equation~\eqref{eq:model-selection} ranks candidates only for the declared common cases, error penalties, and inference charges. The panel is never used for these FP/FN counts. A close loss difference is reported as a sensitivity region.
